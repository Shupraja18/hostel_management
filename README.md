# Hostel Complaint Management System
A full-stack web application for managing hostel complaints efficiently. Students can register complaints and track their status, while administrators can manage and resolve issues through a centralized dashboard.
## Features
- Register hostel complaints
- Track complaint status
- Admin dashboard
- Complaint categorization
- MongoDB database integration
- ## Tech Stack
- Frontend: Html,CSS,React.js
- Backend: Node.js / Express.js
- Database: MongoDB
- ## Installation
1. Clone the repository
git clone https://github.com/Shupraja18/hostel_management.git

2. Navigate to the project folder
cd hostel_management

3. Install dependencies
npm install

4. Start the server
npm start
